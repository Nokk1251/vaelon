1. contact_lookup the name or use the given E.164 number; if the user gives a new number for someone, offer contact_save. 2. Compose a short clear message. 3. make_call with the language of the conversation (e.g. en-US, de-DE, es-ES). The user confirms. If the phone is not set up, say: Settings (⚙) > Phone and email.
